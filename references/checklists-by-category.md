## 通用（所有器件都过一遍）

1. **型号全称与版本后缀**。同一款件的 `-A` / `-B` / `-C` / `-M` / `-P` 后缀通常代表镀膜波段或公英制，选错等于选了另一个器件。
2. **选项族先列全再挑**。同一型号的每个可选维度（光纤族与芯径、镀膜代号、端接、行程、控制器、制冷/非制冷、公英制）按原厂 ordering information / part-number builder 逐族枚举进表，再选；只查到一族就在该行标 ❓ 并进询价清单。（2026-08 评测：只枚举了宽谱光纤族，漏掉 UV-Vis 族里更合适的一档。）
3. **工作波段的真实覆盖**：系列包络 vs 型号覆盖（见 SKILL.md「几条容易犯的错」）。
3b. **小口径镜片：卡住性能的常常是焦距档位，不是通光口径**。给定"元件 ≤ Ø8 mm"这类约束时，先查该口径段**实际存在的焦距档**再算天花板：Thorlabs Ø≤8 mm 的近红外（-C，1050–1700 nm）现货只有 AC050/AC064/AC080 三个消色差系列，**最长 f = 20 mm**，麓邦 LBTEK 同口径能到 **f = 30 mm**（AD205-C，Ø8，但货期 7 周）——**单查一家就会把天花板定低，国产家在小口径长焦档上反而有 Thorlabs 没有的档位**；按孔径算出的束径天花板往往只能用到 60% 左右。结论是"放宽口径也没用"，与"加粗才行"的直觉相反。（2026-09-17 Ø10 紧凑测头选型）
4. **机械接口**：螺纹（SM05 / SM1 / SM2 / M25×0.75 / RMS / C-mount / CS-mount）、安装孔（M4 / M6 / 1/4-20 / 8-32）、光轴高、外形包络。**公英制混用是国内实验室的常见暗坑**，转接件要提前算进 BOM 和交期。
5. **供电与接口**：电压/电流、是否需要独立控制器（常单独计价，且可能比本体贵）、通信口类型。
6. **交期与价格口径**：进口件"8–12 周"是常态；分清**海外库存**与**到货地交期**（发货地、清关方 DDP/DAP）。币种、站点与抓取日期的记录规则见 SKILL.md「候选收集与筛选」的报价规则（Thorlabs / Edmund 官网按 IP 跳转地区站，价格可能是 JPY 或 USD）。国产替代先看交期再看指标。
7. **停产/换代风险**：datasheet 上有没有 "legacy" / "not recommended for new design"。
8. **保修与本地服务**：坏了返厂还是国内修，标定要不要送回原厂；能否借测 / 提供样机。
9. **定制件商务**：NRE / 开模费是否单列；模具、掩模、夹具、版图的归属（写进合同：归我方或可转移）；首件与重复订单分别报价；最小起订与能否拆批；图纸 / GDS 由谁出与确认流程；首件验收不合格的返工费用归属。
10. **生命周期状态要查三家再下结论**：DigiKey 标「停产」、原厂产品页仍列 NEW、Mouser 有现货——三家可以同时成立（原厂换代未同步到分销）。按最坏情况处理（只剩现货），先买保底量，再向原厂问替代料号；报告里把三个来源并列写出。（2026-09-08 激光荧光光源选型）

## 光谱仪

选型的核心是**分辨率与量程的跷跷板**（式子见 formulas.md·A），先算再选。

1. **波段与实际可用段**。标称 500–700 nm 的机器，两端各有一段响应塌陷或信噪极差，实际能用的往往窄一截（某台机器的名义 500–700 nm、实际处理段只有 550–700 nm）。看**响应度/效率曲线**，不看标称范围数字。
2. **采样间隔、光学分辨率、带宽三个量分管三件事**（带宽→峰宽即深度分辨率，按**分析截取段**算、不是光源段；采样间隔→奈奎斯特深度上限；光学分辨率→不改峰宽、只给深度谱乘随深度衰减的灵敏度包络），datasheet 只给一个数时要问清是哪个。**像素数本身不是参数**——先问新机型的波段跨度与像元间距。式子、像素积分因子、"半像元 vs 倍跨度"各改哪个量、可用量程取小的规则与算例见 formulas.md·A。
3. **狭缝宽度**：决定分辨率与通量的折中，且多数机型**出厂固定、不可更换**。选错要重买。
4. **探测器类型与制冷**：CCD / 背照式 / CMOS / InGaAs；有无 TEC（长积分时暗电流是天花板）。
5. **积分时间范围**与**读出速度**。扫描成像时读出速度决定单帧节拍，进而决定一次面扫要几小时；1024 像素机型帧率常减半。
6. **杂散光（stray light）**。最容易被忽略又最伤深度谱——抬底噪、造假峰。要 datasheet 上的 rejection ratio。
7. **接口与 SDK**：USB / GigE；有没有 Python 绑定；能不能拿到**原始 counts**和完整采集参数（而不只是厂家算好的反射率）。原始 counts 与反射率 R 是两种口径，混用静默出错。
8. **光纤接口**：SMA905 / FC-PC；光纤芯径与 NA 要和光谱仪 f/# 匹配，不匹配会损失通量或引入杂散光。
9. **标定周期**与能否自行用汞氩灯复标。
10. **线性度与饱和**：ADC 满量程前是否线性（线性度曲线或 ✅ 实测）；饱和是硬截止还是压缩饱和（压缩饱和读数不可信、无法反推超饱和倍数，曝光又不可调时只能外加衰减器，且所需衰减量无法从饱和读数反推——衰减器按多档 / 可串联买、到货逐档试，档位见光纤节第 3 条）；积分时间最小值与步进。
11. **波长标定与波数线性**（$\sigma = 1/\lambda$ 标尺）：标定多项式阶数与残差（nm）、出厂标定文件能否导出。$\sigma$ 标尺的相对误差 = 深度相对误差，残差非线性 = 峰啁啾展宽。

## 相机 / 探测器

1. **像元尺寸与靶面**，配合系统放大倍率算有效像元（formulas.md·G）。别只看总像素数。
2. **量子效率曲线**在你的工作波段的取值。硅在近红外掉得很快。
3. **满阱容量与读出噪声** → 动态范围。弱信号场景 read noise 比像素数重要得多。
4. **位深**：8/10/12/16 bit，以及高位深是否只在特定读出模式下可用。
5. **快门类型**：全局 vs 卷帘。扫描/运动场景必须全局。
6. **接口**：USB3 / GigE / CoaXPress / Camera Link，采集卡是否另购。
7. **SDK**：语言绑定、是否支持 Halcon / OpenCV 直采、有没有 Python wrapper。换品牌意味着整套采集代码重写，迁移成本计入打分。
8. **触发与同步**：硬触发输入、曝光输出信号，扫描系统里是必需项。
9. **发热与散热**：长时间连续采集时的温漂。

## 显微物镜 / 成像镜头

1. **NA 与工作距离的取舍**。高 NA 意味着短 WD，深孔/深腔测量里 WD 可能是硬门槛。
2. **像差校正等级**（achromat / plan achromat / apochromat）及**校正波段**是否覆盖工作波段。可见光校正的物镜拿到近红外用，色差直接毁掉宽谱干涉。
3. **配套筒镜焦距**。无限远物镜的标称倍率只在原厂指定筒镜下成立（Nikon 200 / Olympus 180 / Zeiss 165 / Leica 200 mm），混搭改变实际倍率。
4. **盖玻片校正**：0 / 0.17 mm / 可调环。样品无盖玻片时选 0。
5. **螺纹**：RMS / M25×0.75 / M26×0.706 / M32×0.75，转接环会略改齐焦距离。
6. **齐焦距离（parfocal length）**：多物镜切换场景关键。
7. **MTF 曲线**。找不到标 ❓——实际封顶常是系统 LSF 而不是理论衍射极限。
8. **镀膜与内部反射**：物镜内部界面的鬼反射会进深度谱变成固定峰。问原厂要不要 AR 版本。
9. **工作距基准面**：不同厂家（镜片顶点 / 镜框端面 / 外壳法兰）基准不同，同一颗镜片两家标的 WD 可差毫米级；外壳出图前用 Zemax 或到货实测定基准。

## 光源 / 激光器

1. **亮度（spectral radiance）而不是功率**，单位 $\mathrm{mW\,mm^{-2}\,sr^{-1}\,nm^{-1}}$。datasheet 通常只给"耦合功率 X mW @ Ø d μm 芯径 / NA"，不同芯径之间完全不可比，按 formulas.md·B 的口径协议反算成工作段谱辐亮度再排名。光斑尺寸被应用定死时，亮度是唯一有意义的比较量。
2. **源的固有尺寸**：弧隙长度（弧光灯）、等离子体尺寸（LDLS）、发光面积（LED）。这是亮度的物理来源，源尺寸差一个量级亮度差两个量级，比灯泡瓦数重要得多。
3. **短期稳定性 vs 长期漂移**，两者不是一回事，datasheet 几乎只给后者。弧光灯有 **arc wander**（秒到分钟尺度的强度与指向抖动）；差分/双腿测量、模板扣除、幅相标定会把短期抖动静默吸收成幅度误差，所以它常比 "<1%/hr" 更致命。厂家不给短期 RMS 是常态——如实标 ❓，写进询价清单，必要时借测实测，不拿长期漂移顶替。脉冲 / 超连续谱源另加两问：**RIN 或脉冲间涨落**（% 或 dBc/Hz，以及积分时间内平均了多少个脉冲 = 重频 × 积分时间）；**工作段 PSD**（dBm/nm 要按你的工作段单独给，不接受 800–1700 nm 的数字）。RIN 不达标时亮度优势作废。
4. **光谱形状**，不只是中心波长和 FWHM。谱形直接决定相干包络与旁瓣，非高斯谱形会出鬼峰；**工作波段内有没有强发射线**（氙、汞弧灯在某些波段有尖锐谱线，会在深度谱里变假峰）——看曲线，不看标称范围。
5. **功率与预热**：预热到稳定要多久。定量测量里稳定性比绝对功率重要。
6. **空间模式与耦合**：能不能耦进单模/多模光纤，耦合效率多少；扩展源耦进小芯径光纤损失极大。输出接口（SMA905 / FC-PC）不匹配时，问原厂能不能直接提供另一种端接的输出光纤——比自己加转接头好。
7. **寿命与耗材**：灯泡/等离子体寿命、更换成本、更换后要不要重新对光。**整机价之外单独算换泡成本**——高亮度光源几年内耗材可能超过整机价。
8. **调制/触发能力**。
9. **安全等级**（激光类）：Class 3B/4 需要防护和管理措施。
10. **冷却方式**：水冷机型要把冷水机、水路和噪声算进集成成本；风冷机型问有没有振动数据。

## 分束器 / 滤光片 / 镀膜件

**这一类是历史坑最多的，逐面确认，不要偷懒。**

1. **每一个光学面的镀膜状态**。分束立方有 4 个外表面 + 1 个内部分光面；棱镜、窗口片同理。问清楚：哪些面镀了、镀的什么（AR-A/B/C、V 膜、宽带增透）、覆盖波段、剩余反射率。
   > 真实教训：某分束立方只有部分通道镀了膜，相机通道那一路是裸 K9，单面 ~4% 菲涅尔反射形成鬼像，实测鬼光约为有效信号的 5 倍。分光比 5:5 完全正确，问题全在没问镀膜。
2. **分光比的波长依赖**："50:50" 通常只在设计波长附近成立，宽谱应用要看分光比 vs 波长曲线；偏振依赖同理，非偏振分束器要专门指定。
3. **两臂色散平衡**。Michelson/Linnik 中**立方**分束器两臂各穿过相同玻璃（去回各一整棱长），天然平衡；**平板**分束器一臂多穿两次基板，必须加同材同厚的补偿板，否则深度谱峰被啁啾展宽；pellicle 无厚度但薄膜自身 etalon 效应会让分光比随波长起伏（~2 μm 厚的 pellicle 光学厚度约 3 μm，恰落在短深度分析窗内）。宽谱干涉优先立方或"平板 + 补偿板"成对买，不要单买平板。Mach–Zehnder 等单程构型两臂玻璃是否相等要单独画光路核。
4. **滤光片的阻带深度（OD）与截止陡度**，以及**角度依赖**——干涉滤光片中心波长随入射角蓝移，非正入射要重算。
5. **面型（$\lambda/4$、$\lambda/10$）与表面质量（scratch-dig）**。干涉测量对面型敏感，成像对 scratch-dig 敏感。
6. **通光孔径 vs 外形尺寸**。标 25.4 mm 的件通光可能只有 22 mm。
7. **楔角/平行度**（窗口片、平板）。平行平板会产生多次反射条纹，需要楔角的场合必须指定。
8. **定制可行性**：非标镀膜原厂能不能做、起订量、加价、交期（镀膜定制常 8 周起）。
9. **作参考面使用的表面不能镀 AR**。可调空气隙标准具、Fizeau 参考板靠那 ~4% 的菲涅尔反射干活；成品楔形窗口的镀膜版两面都镀，会把参考面反射镀没——买未镀膜版（2026-08-13 标定装置报告）。
10. **红外波段的镜垫 / 挡板材料透明性**。硅在 >1.1 μm 透明，1310/1530 nm 干涉仪的镜垫不能拿裸硅面凑数，会打到底下结构；用金膜小镜（2026-08-13）。

## 位移台 / 电控件 / 位移传感

1. **控制接口的可编程性**——先问这个，再问指标。优先级：
   `Python 绑定 > C/C++ SDK > .NET DLL（可 pythonnet，但要折腾）> 只有 GUI 软件（≈不能自动化）> 私有串口协议且不提供文档（否决）`
   > 真实教训：Thorlabs ELL15 电动光阑接上后，Windows 设备管理器只显示一个 FTDI 串口、认不出设备本身，得知道它走 COM7 / 9600 / 地址 0 才能通；官方 ELLO DLL 可以用 pythonnet 调。这类信息 datasheet 首页不会写，要翻通信协议手册或问技术支持。
2. **重复定位精度、分辨率、行程、最小增量步距**，以及**回差（backlash）**。回差经常不在首页。
3. **占空比与热限制**。小型电动件常有"连续工作不超过 X%"的限制（ELL15 是 ≤40%），长时间自动扫描会撞上。
4. **速度与稳定时间**。扫描节拍 = 步进 + 稳定 + 采集，稳定时间常是大头。
5. **负载能力与安装姿态**（垂直安装的额定负载通常砍半）。
6. **是否需要单独控制器/驱动器**，价格和体积。
7. **限位与归零**：上电是否需要 homing、homing 会不会撞样品。
8. **串扰与寄生运动**：Z 向移动伴随的横向漂移。不是纸面指标，要问或实测。
   > 真实教训：某系统实测 Z 深扫伴随约 0.022 μm/μm 的横向漂移，在孔口只有几微米的样品上足以让光斑跑到锥壁。
9. **压电台闭环传感器类型**：电容 vs 应变片（SGS）。长时间保持、nm 级稳定选电容；SGS 漂移与线性都逊。开环压电有蠕变，定量装置必须闭环；驱动器噪声折合位移要亚 nm（2026-08-13）。
10. **位移溯源 / 干涉仪**：要**差分构型**（参考镜贴被测件一侧、测量镜贴运动件，框架漂移变共模），否则框架热漂移全部混进误差；问**周期非线性**（外差式典型 1–2 nm）、死程长度（空气折射率随温度、气压、湿度的漂移都乘它）、测头体积能否塞进被测探头下方的空间；Abbe 误差与双头抵消、热胀系数见 formulas.md·F。

## 机械件 / 笼式系统

1. **笼式规格**：30 mm（SM1 / ER 杆）vs 16 mm（SM05）vs 60 mm，跨系统要转接板。
2. **光轴高**统一（常见 3 in / 75 mm），不统一就要垫块，垫块引入角度误差。
3. **公英制**：M6 vs 1/4-20 面包板，M4 vs 8-32。
4. **调整机构**：镜架调节分辨率与热稳定性（μrad/°C），长时间测量要看；结构件材料热胀系数与测量环路长度一起算（系数与算例见 formulas.md·F）。
5. **小口径准直器 / 透镜的外壳螺纹与转接件存在性**：Ø11 壳 M11×0.5、Ø12 壳 M12×0.5、M9×0.5 各不相同，**先查有没有到 SM05/SM1 的转接件再选壳**——Thorlabs 没有 M12→SM05 件，F240 这类 Ø12 壳在 SM05 体系里直接出局（2026-08-04 测头报告）。

## 光纤与光纤无源器件

1. **单模 / 多模与工作波长**：截止波长、MFD（单模算耦合用 MFD 不用芯径，formulas.md·C）、在工作波长是否已变多模或接近截止。
2. **端面与回损**：PC / UPC / APC；回损 dB 与它在深度谱里对应的峰（formulas.md·D/E）；APC 出射有偏折（角度见 formulas.md·C），适配板 / 准直器要选带角度补偿的版本；FC 键宽 2.0 / 2.2 mm 要与跳线配对，键槽游隙会让 APC 方位角转动、补偿方向错位。
3. **在线器件的口径**：反射式共路光双程穿过，衰减 / 插损按 formulas.md·E 折成双程再与门槛比（厂家标称是单程透射法，按单程数字买会把衰减买成两倍）。所需衰减量不能从饱和读数反推时，按多档 / 可串联买、到货逐档试。
4. **构造**：掺杂吸收型（无腔，首选）vs 空气隙型（两端面隔几十到几百 μm，腔长落在检测窗内必造固定峰——一票否决）vs 错位对接 / 高损熔接型（无腔，但回损与平坦度差，按第 2、5 条审）。国产通用件普遍不标构造，买样到货用本系统实测兜底（2026-08-18 衰减器报告）。
5. **波长平坦度与 PDL**（±dB / ±nm），宽谱应用要曲线。
6. **NA / 芯径与光谱仪 f/# 匹配**；NA 失配是通量损失的隐形来源。
7. **弯曲半径**与端面清洁（每次插拔前清洁，脏端面本身是反射源和损耗源）。
8. **光纤族要列全**：同一光源 / 仪器常有 UV-Vis 耐日晒族与宽谱族，芯径档不同、功率不同，按通用第 2 条逐族枚举。
9. **通信无源件厂的"光纤准直器/聚焦器"做不出小束腰**。该产品线的束腰最小只到 **0.35–0.45 mm**（DK-Photonics Ø1.8 mm C/G-lens 实测 0.42–0.45 mm），"聚焦器"指的是聚到几百 µm 用于远距对接，**不是 OCT 探头要的 10–50 µm**。要小束腰只有两条路：OZ Optics `LPF` 这类料号里能直接指定**放大率 M 与工作距**的定制件（光斑 = 放大率 × 芯径，60 dB 回损在 1310/1550 nm 是标配），或自己配准直镜 + 聚焦镜两片。Thorlabs 全线**没有**小束腰 focuser 成品。（2026-09-17 Ø10 紧凑测头选型）
10. **插座式（receptacle）光纤准直/聚焦器的最小外径被 FC 接口卡死**：OZ 插座式最小 **Ø11.00 mm**（HPUCO/HPUFO-T3，M11×0.5），Ø12 次之。**探头外径 ≤10 mm 时只能走尾纤式（pigtail）**，FC/APC 接头放在光纤另一端；自做 M8×0.75 凸台的 FC 座是唯一能压进 Ø10 的做法，需自行核算螺母外径。（同上报告）

## 软件与授权

1. **授权模式**：永久 / 订阅 / 按月评估 / 加密狗 / 浮动许可。
   > 真实教训：某机器上的 Halcon 是按月评估授权，过期表现为报 `#2042` 或预览全黑，看起来像硬件故障。选型时问清"授权到期表现成什么样"并记录续期检查方式。
2. **绑定方式**：绑机器码还是加密狗，换机器/重装系统会不会失效。
3. **运行时授权**：开发授权与部署运行时授权通常分开计价，预算里常漏。
4. **语言绑定与版本兼容**：Python 版本、.NET 版本、与现有环境冲不冲突。
5. **离线可用性**：实验室机器常不联网。

## 定制加工 / 服务采购

流片、定制镀膜、定制光纤、机加件、委托测试。对象不是货架器件时，"镀膜 / 接口"类检查项让位于下面这些（模板「逐项体检」的行集也按此替换）。证据五级照用，映射：先例照片 / 工艺考核报告 / 实测表征 = ✅；机构官方设备清单、服务目录、公开工艺能力表 = 📄；新闻稿、第三方报道、销售口头 = 💬；金额估计 = 💬估。

0. **先问现有件 / 样品的来源方**有无现成档位或报废片——同源版本省 NRE、省验收，零成本先发这一问。
1. **接单形态**：单件 vs NRE + 批量、最小起订、科研小单是否接、项目制还是开放平台。
2. **工艺能力证据**：要先例照片 / 实测报告 / 工艺考核片，不要网页口号；问清极限档位的实际良率。
3. **表征 / 检验报告**是否随件交付、由谁出、用什么口径——关键尺寸的定义与测量位置（如开口处还是中部、哪个面的哪个方向）由需求方在询单里明确指定，以交付表征为准。
4. **设计文件 / 模具 / 掩模的归属**与重复下单价（首件 vs 第二批）。
5. **良率、返工、不合格处置**条款；分档加工时各档预期偏差（不同尺寸同批加工常得到不同深度/宽度）要事先写明。
6. **报价全 ❓ 时**，量级估计标 💬估 并写明估计依据（同类服务公开价、类似单据），不得写成 📄。
