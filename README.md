# optics-device-survey

光学与检测硬件的选型调研 skill，用于 Claude Code / DeepSeek Harness 等能读 `SKILL.md` 的 agent。

**一句话**：从测量任务反推硬门槛 → 联网收候选 → 逐项体检原厂资料 → 口径归一化 → 硬门槛先于打分 → 带证据链的报告与询价清单。

选型翻车几乎从来不是"主指标没看"，而是主指标之外的东西：分光比选对了但某一面是裸玻璃；电控件参数全达标但 SDK 只有 .NET；光谱仪标称波段够用、实际处理段窄一截。所以这个 skill 的重心不在"找参数最好的"，而在把标称值之外的隐藏成本挖出来，并且让每个数字都能回答"这是原厂 datasheet 上的，还是代理页上脑补的"。

## 适用 / 不适用

**适用**：任何光学或检测硬件的选、买、换、比价、尽调——光谱仪、相机、物镜、镜头、光源、激光器、分束镜、滤光片、镀膜件、位移台、压电台、干涉仪、电控光阑、载物台、光纤与无源器件、笼式与机械件、采集卡、商业软件授权；也包括测头 / 标定装置这类小系统的多件 BOM，以及定制样品、流片、加工服务的渠道调研。

**不适用**：开源库 / 框架选型；算法或处理参数（窗函数、滤波、重采样、阈值）的取舍；已有设备的故障排查。

## 三档产出

| 档 | 触发问句 | 产出 |
|---|---|---|
| A 快速判断 | "XX 够不够用""这个参数什么意思""要不要换成 XX" | 需求卡两行 + 指标推导（公式后必须跟"代入我们的数字"的算例）+ 至多 3 条该类器件要领，不搜候选 |
| B 单品尽调 | 用户已给型号 | 在 A 的基础上加逐项体检（含选项族核对）、询价问题、采购建议与验收表，跳过候选收集与打分 |
| C 完整调研 | 要从零选一件 / 一套 | 八步全做 |

## 八步流程

1. **需求卡** —— 测量任务、接入的现有系统、预算与交期（写成假设 + 敏感性，不阻塞）、地域渠道、新建还是替换、自建还是成品；多件子系统先做误差预算，指出哪 1–2 件决定性能。
2. **指标推导** —— 不照抄用户口头参数，从测量任务自己算一遍门槛，列成硬门槛表（指标 / 门槛值 / 推导依据 / 一票否决 or 可打分）；口径（单程双程、FFT 格距还是加窗 FWHM、空气还是介质内）必须写在旁边。
3. **候选收集与筛选** —— 原厂优先，参数一律回原厂 datasheet；门槛状态用 ✅ 已证满足 / ❌ 已证不满足 / ⚠ 带条件进细审 / ➖ 未细审 / 🔁 过渡对照。
4. **逐项体检** —— 按器件类别过清单，每条标证据等级：✅ 实测/曲线、📄 标称、🧮 反算（必须写算式）、💬 口头/估计、❓ 缺失；同一参数多来源冲突时两个都列。
5. **口径归一化** —— 打分前把厂家数字折算到你的工作点：拿 étendue 换功率、拿带宽/时间换信噪、拿工作点换精度。
6. **打分** —— 先过硬门槛再打分，门槛不过不许用高分捞回来；维度与权重可按场景调，调了要写理由。
7. **询价前要问掉的问题** —— 按收件人分组成表，标阻断性；定制件固定追问 NRE、模具归属、第二批单价。
8. **采购建议与验收** —— 建议动作、BOM（转接件/控制器/线缆/工装是最常漏的）、自建 vs 成品的真实代价、验收表（数值 + 处置，不写"看是否正常"）。

## 安装

Claude Code：

```powershell
Copy-Item -Recurse . "$env:USERPROFILE\.claude\skills\optics-device-survey"
```

DeepSeek Harness（skill 根目录为 `$env:DSH_HOME\skills`）：

```powershell
Copy-Item -Recurse . "$env:DSH_HOME\skills\optics-device-survey"
```

复制后重开会话即可出现在 skill 列表里；也可以直接点名调用，或把需求卡初稿当参数带进去。

## 来历

2026-08 编写；2026-08-21 经三轮审计重写（自审 + 多视角评审 + 反驳者核验，一次约 15 个 agent），2026-09-17 更新分类清单。内部真实用过 5 次，其中只有 2 次是纯器件选型，所以才把产出分成三档——完整调研并不总是值得。

两个来自修改过程的提醒：

- 审计抓到的两个 P0 错误都是重写时**新引入**的（一个分母取错、一个 dB 与滚降深度换算错），而不是原稿留下的。改这个 skill 时，凡自己新写的物理句——系数、口径、dB 换算、分母取什么——都要独立代数复算一遍，或交给一个专门的物理审查者。
- `references/lab-baseline.template.md` 只是模板，里面的波段、峰位、型号都是占位符。填基线时必须来自项目自己的文档；把别处系统的数值顺手抄进来是这个 skill 最容易发生也最难发现的错误。
